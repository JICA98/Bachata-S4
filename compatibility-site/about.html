Bachata S4

About Bachata S4

Bachata S4 is an experimental PlayStation 4 emulator project focused on modern ARM64 Android devices.

What the project does

Bachata S4 combines an Android frontend, the shadPS4 emulator core, FEX-based x86-64 guest execution, a managed Linux runtime, and Vulkan rendering. Compatibility varies by game, device, Android version, driver, and emulator release.

Open-source core

The maintained emulator core is developed publicly at zenithblue-oss/shadps4-arm64. This repository hosts Bachata S4 releases, the compatibility website, and project coordination.

Compatibility evidence

Compatibility results are based on recorded tests. A status reflects the tested configuration only and is not a promise that the same title will behave identically on another device.
