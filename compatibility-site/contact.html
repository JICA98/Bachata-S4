GitHub issues

The project is developed in public on GitHub. The best way to reach the maintainers and the community is through the issue tracker:

Open GitHub issues

  • Game compatibility reports and discussions — search for the game's exact CUSA ID before opening a new issue; one canonical issue is kept per game. Use the game-report label.
  • Bugs and feature requests — open a new issue in JICA98/Bachata-S4.
  • Compatibility data corrections — submit a pull request to JICA98/Bachata-S4-Compatibility.

Before you report

For compatibility problems, include the Bachata S4 release and exact commit, your phone model, SoC, GPU, Android version, the selected graphics driver, reproduction steps, and a sanitized session log where possible. Reports are most useful when they can be reproduced.

Website problems

If this website itself has a problem, please open an issue and mention the page and what you observed.
