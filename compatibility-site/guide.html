Bachata S4

Quick start guide

A short path from installation to a useful compatibility test.

Install

Use the supported Bachata S4 release for your device and complete the app runtime setup.

Choose a graphics driver

Use a compatible system driver or an appropriate Mesa Turnip/custom driver. Driver choice can materially change correctness and performance.

Test legally owned content

Import only homebrew or software you are legally entitled to use. Let initial shader or pipeline compilation finish before judging performance.

Compare reports

Open the compatibility database and compare against reports from similar hardware, Android versions, and graphics drivers.
