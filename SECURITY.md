# Security policy

Please report suspected Bachata S4 security vulnerabilities through GitHub's private vulnerability reporting interface for this repository. If that interface is unavailable, open a minimal issue asking a maintainer for a private contact channel without disclosing vulnerability details.

Do not publish credentials, signing material, account data, access tokens, encryption or console keys, private logs, device identifiers, copyrighted games, firmware, or other copyrighted content. Provide only the smallest privacy-safe reproduction material after a maintainer establishes a private channel.

Public issues and pull requests are appropriate for ordinary compatibility, site, and documentation defects that do not expose sensitive information.
