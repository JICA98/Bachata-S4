# Compatibility reports

This directory is the public, evidence-only compatibility feed. Each JSON
report must match [`schema-v1.json`](schema-v1.json) and identify one game,
one Bachata S4 release, one device, and one graphics driver.

Reports contain no ADB serials, private logs, game dumps, firmware, keys, or
proprietary implementation details. Do not publish a report without a
legally owned game test and reproducible release/device/driver evidence.

The clean-room hardening baseline publishes the schema and validation workflow;
game reports are added only after that evidence review.
